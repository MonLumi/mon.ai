# mon.ai — project rules for Claude

## Git
- You are free to commit and push without asking first. This covers committing straight to `main` and pushing to `origin`.
- Don't force-push and don't rewrite published history unless asked.

## Restarting the app
- Never offer, ask about or show a card/button for restarting mon.ai (`npm run restart`, `mon.ps1`, etc.). The user always restarts it themselves.
- After a change, you may mention once that it takes effect after a restart, but don't ask about it.
